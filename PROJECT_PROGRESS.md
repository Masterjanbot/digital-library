## Run with Docker Compose (Windows CMD)
From the extracted project directory:

```cmd
copy .env.example .env
notepad .env
docker compose config
docker compose up --build
```

In another CMD window, create an administrator:

```cmd
docker compose exec backend python manage.py createsuperadmin
```

Open `http://localhost:8081`. Do not remove Docker volumes when rebuilding; the database and uploaded files are persistent.
